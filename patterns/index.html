Patterns

Architecture and delivery patterns reviewed in depth — one page per pattern: the problem it solves, how it works, the platforms that implement it, and the delivery leader's lens.

Each pattern below links to a full visual explainer. The lifecycle column says where in a programme's life the pattern earns its place.

PatternLifecycle aspect it servesThe problem it solves
Data Fabric Foundations → Scale
Data platform & governance backbone of a transformation — laid early, then every later stream (analytics, AI, data products) builds on it.		 Silo sprawl: N consumers × M data stores, each with its own copies, access rules, and version of the truth. The fabric leaves data in place and governs it through one metadata-driven layer.
Event-Driven Architecture Foundations
The communication backbone of a modern estate — the from-first-principles page: how systems historically talked, what kept breaking, and why the event log fixed it.		 Request/response used for everything: a tangle of direct connections, cascading failures down waiting chains, overnight-batch stale data, and no history of how state got the way it is.
Event-Driven Agents Scale → AI workstreams
Coordination backbone for agentic AI — how single agents become governable multi-agent systems once GenAI initiatives move past the pilot. Builds on the EDA page.		 Agents wired together with rigid request/response APIs collapse under coupling, stale data, and unrecoverable failures. Event streams give them decoupling, replayable recovery, and an audit trail in one move.
