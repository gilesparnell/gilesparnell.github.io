Internal platform

Parnell Systems Platform

An internal operations console for running a voice and messaging product — one place to manage numbers, communication channels, and per-client demo environments.

Next.jsTypeScriptPostgres
The problem

Running a voice-and-messaging product means juggling phone numbers, several communication channels, and separate demo setups for each prospective client. Doing that across a handful of disconnected vendor dashboards is slow and error-prone.

What was built

A single internal platform that brings those jobs together: managing numbers, handling voice and messaging in one place, spinning up client-specific demo views, and administering who has access. It is built as a modern web application with a typed codebase and a proper database behind it.

The outcome

Day-to-day operations run from one console instead of many, which makes setting up a new client demo and keeping the product running faster and less fragile. Built with Next.js and TypeScript on a Postgres database.

Source code and implementation docs for this project are private.
